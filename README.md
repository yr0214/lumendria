# 🌑 루멘드리아

> **모든 선택은 누군가의 운명이 된다.**

당신의 동생은 3년 전, 저주받은 왕국 **아에르돈**에서 죽었습니다.

사인은 **'저주병'.**

왕국 밖에서는 존재하지도 않는 병.

3년 동안 진실을 쫓은 끝에,
당신은 국경을 넘어 이곳에 도착합니다.

하지만 이곳에서 가장 위험한 것은 괴물이 아닙니다.

**진실입니다.**

# ✨ 게임 특징

### 🌿 선택이 이야기를 만든다

모든 선택은 이후의 이야기를 바꿉니다.

- 누구를 구할 것인가
- 누구를 믿을 것인가
- 무엇을 희생할 것인가
- 어떤 진실을 받아들일 것인가

정답은 없습니다.

선택에는 반드시 대가가 따릅니다.

---

### 🗡 하나의 선택이 수많은 미래를 만든다

- 숲으로 향할 것인가
- 마을을 조사할 것인가
- 왕을 만날 것인가
- 마법사를 믿을 것인가
- 저주받은 유물을 사용할 것인가

당신이 지나간 길은
다음 플레이에서 완전히 다른 이야기가 됩니다.

---

### 🌙 9개의 엔딩

당신의 선택은 하나의 결말로 이어집니다.

- 왕의 회개
- 왕좌의 그림자
- 빛의 대가
- 저주를 끊은 새벽
- 왕국의 침묵
- 이름을 바친 밤
- 성문 너머의 도주
- 늑대의 문장
- 성문 아래의 끝

그리고...

모든 엔딩을 본 사람만이
마지막 이야기에 도달할 수 있습니다.

# 📖 한 편의 다크 판타지

루멘드리아는 전투보다 **이야기**에 집중한 인터랙티브 웹게임입니다.

당신은 선택하고,

탐색하고,

의심하고,

진실을 모으며

하나의 결말에 도달합니다.

하지만 그 결말은 끝이 아닙니다.

새로운 선택은
또 다른 진실을 보여줍니다.
